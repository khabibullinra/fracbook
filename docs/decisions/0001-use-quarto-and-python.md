# ADR-0001: Quarto + Python как стек публикации

## Статус

Принято, июль 2026.

## Контекст

Методичка по курсу ГРП должна быть:

- опубликована как сайт на GitVerse Pages;
- доступна для студентов с Windows (Positron) и для преподавателя с Linux;
- пригодна для встраивания Python-расчётов с графиками;
- сопровождаться расчётной библиотекой, которую можно переиспользовать в ноутбуках.

## Решение

- **Quarto ≥ 1.9** — генератор сайта. Поддерживает Python-чанки, формулы (LaTeX/MathJax),
  библиографию, мультиязычность, кастомные темы.
- **Python ≥ 3.12** в `.venv` — расчётная среда. Пакет `fracbook` живёт в `src/fracbook/`,
  ставится в editable-режиме (`pip install -e .[dev]`).
- **Локальный рендер** преподавателем + force-push в ветку `pages` (стратегия B).
- **CI** не развёртывает, только smoke-test (`pytest` + `ruff`). Проверка `.qmd` — локально перед PR (через `quarto render book/`) и при ручной публикации (`tools/publish-pages.sh`).

## Последствия

- Один инструмент публикации — Quarto. Не нужен отдельный шаблонизатор.
- Версия Quarto зафиксирована (≥ 1.9); все участники должны использовать совместимую.
  В CI ставится 1.9.38 для воспроизводимости.
- Python через `.venv` — обязателен. Никаких глобальных установок.
- Стратегия B (локальный рендер + force-push в `pages`) проще автоматического деплоя,
  но требует от преподавателя дисциплины: пуш в `pages` только после локальной проверки
  (`./tools/publish-pages.sh` сам делает нужные проверки).
- Quarto и `fracbook` развиваются независимо. Расчётная библиотека переиспользуется
  в `book/`, `notebooks/`, может быть опубликована отдельно.

## Альтернативы, которые отклонили

- **Jupyter Book** — хороший, но требует Python-окружение в Pages, что GitVerse Pages
  не поддерживает (только статика).
- **Sphinx + ReadTheDocs** — мощно, но не встроен в Quarto и не так дружелюбен к формулам
  в Pandoc-стиле.
- **MkDocs / Docusaurus** — слабее поддержка Python-чанков и формул.
- **Статический HTML руками** — не масштабируется.
