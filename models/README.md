# Модели гидродинамических симуляторов

Текстовые описания моделей для гидродинамических симуляторов (tNavigator и др.),
скрипты запуска и воспроизведения.

## Раскладка

```
models/
├── README.md                   # этот файл
└── <simulator>/
    ├── _template/              # заготовка, копируется при создании новой модели
    │   ├── README.md
    │   ├── data/
    │   ├── include/
    │   ├── grid/
    │   └── run.sh
    └── NN-<slug>/              # конкретная модель (NN — двузначный номер)
        ├── README.md
        ├── data/
        ├── include/
        ├── grid/
        └── run.sh
```

`<simulator>` — `tNavigator`, `eclipse`, `tnavigator-mock` и т.п. По мере появления
новых симуляторов заводится новая подпапка того же уровня.

## Как завести новую модель

1. Скопировать `models/<simulator>/_template/` в `models/<simulator>/<NN-slug>/`.
2. Переименовать `data/MODEL.data` под свою модель (или создать новые файлы).
3. Заполнить `README.md`:
   - что моделирует (физика, геометрия, цель эксперимента);
   - параметры (пласт, флюиды, трещина, скважина);
   - команды для воспроизведения (`./run.sh` или ручные шаги);
   - ожидаемые результаты (графики, метрики, файлы).
4. Проверить, что бинарные артефакты не попадут в коммит (см. ниже).

## Что НЕ коммитить

В `.gitignore` корня репо уже исключены:

- `*.geos`, `*.geos.gz`, `*.unrst`, `*.unrst.gz`
- `*.EGRID`, `*.EGRID.gz`, `*.INIT`, `*.INIT.gz`
- `*.UNSMRY`, `*.SMSPEC`, `*.RSSPEC`, `*.GRDECL`, `*.UNRST`
- `*.MSG`, `*.PRT`, `*.log`, `*.dbg`, `*.RSM`

Это бинарные/служебные выходы симулятора. В репо — только текстовые исходники
(`.data`, `include`-секции, `schedule.inc`) и скрипты воспроизведения (`run.sh`/`build.sh`).

## Когда `models/` вам НЕ нужен

Если ваша работа в основном аналитическая (через `fracbook`), вам сюда заходить не нужно.
Папка — для тех, кто гоняет полноценные гидродинамические модели.
